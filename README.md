# أوركيد لحلول التقنية

موقع عربي ثابت باتجاه RTL لخدمات التقنية وتهيئة منصة EMPID. النطاق: `https://orkeed.com/`، والبريد: `info@orkeed.com`.

## البناء والمعاينة

من `D:\orkeed` شغّل `python tools/build_blog.py` ثم `python -m http.server 4175`، وافتح `http://127.0.0.1:4175/`.

توجد الصفحة الرئيسية في `index.html`، ومصدر المقالات الـ16 في `content/posts.json`. يولّد `tools/build_blog.py` صفحات المدونة وملف `sitemap.xml`. الهوية موثقة في `BRAND.md`، وإعدادات البحث في `SEO.md`.

صور المقالات التوضيحية WebP مضغوطة وبحجمين 480 و1200 بكسل. لقطات EMPID مأخوذة من بيئة عرض الأفق العربية ببيانات اختبار. لا يستخدم الموقع شعار أو بانر الموقعين السابقين.

عند النشر، ضع الملفات في جذر النطاق، وتحقق من عمل HTTPS والبريد. زر التواصل يفتح تطبيق البريد لدى الزائر؛ لا توجد استمارة تجمع بياناته.
